# SKALA 스토어 멤버십 정책

문서 버전: 2026-08-20

## 등급 산정

멤버십은 일반, 실버, 골드 등급으로 운영한다. 최근 6개월의 구매 확정 금액을 매월 1일에
계산하며 20만 원 이상은 실버, 50만 원 이상은 골드 등급이 된다.

## 포인트 적립

일반 회원은 결제 금액의 0.5%, 실버 회원은 1%, 골드 회원은 3%를 포인트로 적립한다.
포인트는 배송 완료 7일 뒤 구매가 확정되면 지급한다. 쿠폰 할인 금액과 배송비는 적립에서 제외한다.

## 포인트 사용과 소멸

적립 포인트는 1,000점부터 100점 단위로 사용할 수 있다. 포인트 유효기간은 적립일부터
12개월이며 기간이 지나면 매월 말일에 자동 소멸한다.
