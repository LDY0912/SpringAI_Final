# SKALA 스토어 반품·교환 정책

문서 버전: 2026-08-20

## 단순 변심 반품

단순 변심으로 반품하려면 상품을 받은 날부터 7일 이내에 신청해야 한다. 상품을 사용하거나
훼손해 가치가 감소한 경우에는 반품할 수 없다. 고객의 주문에 따라 별도로 제작된 상품과
신선식품도 단순 변심 반품 대상이 아니다.

단순 변심 반품의 왕복 배송비는 고객이 부담한다. 기본 왕복 배송비는 6,000원이며 제주와
도서산간 지역은 실제 추가 운임이 함께 부과된다. 반품 접수 후 고객센터가 회수 일정을
안내하고, 회수 기사가 보통 1~2영업일 안에 방문한다.

## 하자와 오배송

상품 하자나 오배송은 상품 수령일부터 30일 이내에 접수할 수 있다. 이 경우 회수와 재배송에
드는 비용은 회사가 부담한다. 사진으로 하자나 오배송 사실을 확인한 뒤 교환 또는 환불을
진행한다.

## 환불과 교환 처리

카드 결제는 반품 상품 확인 후 3영업일 이내에 승인 취소한다. 계좌 이체 금액은 확인 후
1영업일 이내에 입금하며, 사용한 포인트는 즉시 복원한다. 교환 상품은 회수 완료 뒤 통상
2~3영업일 이내에 다시 발송한다.
